## 🛠️ Video Editlerne Kılavuzu (CapCut / Premiere / DaVinci)

```
1. Kaynak klibi import et (zolttran-teaser-source.mp4)
2. Müziği ekle, ritme göre kes
3. Screen recording: VS Code + Zolttran kullanımını kaydet
4. Görsel 1-6'yı arka plan / overlay olarak ekle
5. Başlık: "ZOLTTRAN" → Gradient efekti (#7c6af7 → #22d3ee)
6. Alt yazı: Beyaz, minimal font (Inter / Geist)
7. Son kare: Logo + GitHub URL + Yıldız CTA
8. Export: 1080p/4K, H.264, %90 quality
```
